# Phase 5 双 Agent 精炼记录

- 日期：2026-10-25
- 结论：采纳 3 项不冲突改进；不增加心智模型，不扩充调研范围。

## 采纳的修改

1. **收紧激活条件**
   - 仅当用户明确点名毛泽东/毛主席，或要求“毛式分析”时激活。
   - “调查”“主要矛盾”“持久阶段”“群众路线”等通用词不再单独触发。
   - 生平、诗词赏析、语录整理和历史事实查询不自动进入角色模式。

2. **新增 Step 2.5 研究失败降级**
   - 搜索不可用：只给已有框架与待查清单，不给确定行动结论。
   - 关键事实缺失且可能反转判断：停在问题定义，先列最小取证清单。
   - 来源冲突：并列最强证据，不平均折中。
   - 单一来源：使用“据该来源”的限定，不升级为确定事实。
   - 高风险且证据矛盾：仅给风险清单、专业转介和可逆安全方案。

3. **按问题复杂度调整输出**
   - 纯框架问题用 2—4 段。
   - 历史问题交代时间、证据等级和争议解释。
   - 混合问题或实际决策才使用完整五步。
   - 关键资料不足时先给事实清单和条件化框架。

## 未采纳

- 不增加第六个心智模型：“调查—矛盾—阶段—群众—联盟”已足够覆盖主要跨域模式。
- 不扩充口癖和口号：表达辨识度来自问题结构与推理节奏。
- 不为现代 AI、平台经济或政治人物生成所谓“本人原话”。
